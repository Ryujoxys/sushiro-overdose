# v4.0.3 · lite正式版

2026-10 起寿司郎小程序换了实时接口：叫号不再允许匿名读取，要用你自己的小程序登录（约 1 小时有效）。这一版让应用在两种情况下都能用。

## 不连接也能用

- **按叫号算几点叫到**：在小程序里看一眼现在叫到几号，填上你的号码，应用按这家店以往的叫号速度推算大概几点叫到，给出早晚区间和出发建议。用 9 月的真实记录回测，提前 1 小时预测的平均误差约 18 分钟。
- **想几点吃**：本机记录不够时，按这家店以往同类日子的等待规律给出取号时间；可以填路上要多久。
- **选门店**：实时门店列表取不到时，用内置历史和本机记录里的门店，照样可以按城市、区域搜索。
- **记一笔**：把小程序里看到的叫号记在这台电脑上，用来校准叫到时间和叫号提醒。
- 所有历史推算都标明“历史截至 2026-09-06”，不冒充实时数据。

## 连接后恢复实时

- 设置里新增「实时数据」：用手机或电脑微信经本应用打开寿司郎小程序刷新一下，或粘贴抓包工具里的一条请求，就能连上；显示还剩多少分钟，到期前提示。
- 连接后实时叫号、在等桌数、官方预估、记录和叫号提醒恢复；连接期间经本应用打开小程序看到的门店数据也会顺手记下。
- 连接只保存在这台电脑上，只发给寿司郎的新接口；到期或被拒就停，不会反复重试。应用不模拟微信、不自动续期。

## 更稳

- 取号前查不清你现在有没有号时，直接拒绝提交并提示去小程序里取号，不会冒险重复取号。
- 实时数据取不到时不再提示“关闭海外 VPN”，而是说明需要连接；不再显示 HTTP 状态码。
- 记录失败时按原因放慢重试，需要连接时停下来等你连接，不再每 30 秒请求一次。
- 关掉窗口后的独立后台不使用你的登录，所以不再记录；“登录电脑后启动后台”只对仍开着它的人显示，方便关闭。

## 数据与工具

- 全国门店历史排队数据每天同步到仓库 `data` 分支，无需账号；配套 Claude 技能 `sushiro-queue` 可直接回答“几点去、几点叫到”。

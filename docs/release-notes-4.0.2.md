# v4.0.2 · lite正式版

记录常去门店的排队情况，按时间看通常叫到几号、要等多久，需要时手动取号。数据留在本机。

## 看规律

- **一眼看懂**：图表上方用一句话说明几点最挤、通常要等多久，几点基本不用等；最挤时段记录少时会提示仅供参考。
- 图表重画：纵轴改成整数刻度（0 / 500 / 1000…）并标出单位，横轴按整点显示；选中时段有竖线标记，数值提示放在图上方，不再挡住曲线。记录天数较少的时段用空心点标出。
- 读数改成白话：「约 2 小时 45 分」「基本不用等」「常见 535–1244 号」「八成日子不超过 2 小时 55 分」，不再出现中位数、分位、样本等术语。
- 记录区合成一张卡：一行看清「记录中 · 每 5 分钟记一次 · 上次记录：3 分钟前」；每家店显示多久前记过一次，长时间没有新记录会变成黄色提醒；正在图表里查看的店有标记。
- 筛选收成一行（门店、时间范围、日期类型、只看一天、含内置历史），导出移到卡片底部；切换筛选时保留旧图变淡，不再闪烁。
- **今天 vs 平时**：查看多日规律时，图表叠加今天自己记录到的曲线，读数里同时给出「通常」和「今天」的叫号与等待。
- 门店列表直接显示最近一次记录叫到几号。
- 第一次打开时顶部显示「选常去的店 → 开始记录 → 看自己的规律」三步，有了第一条记录后自动收起；没有数据时不再显示一排 0。
- 未开始记录时不再误显示「已暂停采集」。

## 数据

- **从备份恢复**：设置页可以导入之前「备份全部记录」导出的文件，只补充缺少的记录，不覆盖、不删除现有数据，重复导入会自动跳过。换电脑时也能带走自己的记录。
- 导出文件名带上日期，多次备份不会互相覆盖。

## 取号

- 取到号后显示当前叫到几号、还差几号和进度条；停在取号页时每 30 秒随实时排队一起刷新预计入座时间。号码比当前叫号还小时提示可能已过号。
- 实时排队显示「刚刚 / 几分钟前」更新；门店面板可以直接跳到这家店的历史规律。
- 选店时，已选和常去的门店排在最前面，不用再搜索。
- 读取排队失败时给出能看懂的原因：例如被服务器拒绝时提示关闭海外 VPN / 代理，不再显示原始网页代码或网络细节。

## 外观

- **深色模式**：页面、图表和原生窗口跟随系统外观自动切换。
- 桌面窗口滚动时顶部导航保持可见；时段滑块、按钮和卡片间距统一调整。

## 设置

- 新增「版本与更新」，只有点击「检查更新」时才访问 GitHub 发布页；有新版本时可直接打开下载页。开源许可收进同一张卡片。

## 维护

- 清理自动抢号下线后遗留的未使用代码，行为不变；依赖经漏洞扫描未发现已知问题。

## 下载

macOS 12+ 选择 DMG，兼容 Intel 和 Apple 芯片。Windows 10/11 选择对应架构的 EXE；缺少 WebView2 时按提示安装。压缩包提供 CLI/浏览器版本。

升级前在「设置 → 应用与后台」退出旧版本及后台记录，再替换程序。本机数据保留。macOS 安装包未配置开发者签名时会提示来源未知，请确认从本仓库下载后再允许打开。

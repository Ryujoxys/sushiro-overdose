# v4.0.2 · lite正式版

记录常去门店的排队情况，按时间看通常叫到几号、要等多久，需要时手动取号。数据留在本机。

## 这次的变化

- **深色模式**：页面、图表和原生窗口跟随系统外观自动切换。
- **第一次打开更清楚**：顶部显示「选常去的店 → 开始记录 → 看自己的规律」三步，有了第一条记录后自动收起；没有数据时不再显示一排 0。
- **取到号之后**：号码旁显示当前叫到几号、还差几号和进度条；停留在取号页时每 30 秒随实时排队一起刷新预计入座时间。号码比当前叫号还小时直接提示可能已过号。
- **实时排队**：更新时间显示为「刚刚 / 几分钟前」，刷新按钮与说明对齐。
- **检查更新**：设置页新增「版本与更新」，只有点击时才访问 GitHub 发布页；有新版本时可直接打开下载页。开源许可收进同一张卡片。
- 桌面窗口顶部导航在滚动时保持可见；未开始记录时不再误显示「已暂停采集」。

## 维护

- 清理自动抢号下线后遗留的未使用代码，行为不变。
- 依赖经漏洞扫描未发现已知问题。

## 下载

macOS 12+ 选择 DMG，兼容 Intel 和 Apple 芯片。Windows 10/11 选择对应架构的 EXE；缺少 WebView2 时按提示安装。压缩包提供 CLI/浏览器版本。

升级前在「设置 → 应用与后台」退出旧版本及后台记录，再替换程序。本机数据保留。macOS 安装包未配置开发者签名时会提示来源未知，请确认从本仓库下载后再允许打开。

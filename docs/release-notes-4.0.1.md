# v4.0.1 · lite正式版

记录常去门店的排队情况，按时间看通常叫到几号、要等多久，需要时手动取号。数据留在本机。

## 桌面使用

- Windows 和 macOS 使用独立原生窗口，重复打开唤起已有窗口。
- 已开启的后台记录不随窗口关闭而停止；账号认证随界面退出清理。
- 记录和诊断包通过系统保存框导出。
- 首次打开可查看截至 2026-09-06 的固定历史，支持只看自己收集的数据。

## 下载

macOS 12+ 选择 DMG，兼容 Intel 和 Apple 芯片。Windows 10/11 选择对应架构的 EXE；缺少 WebView2 时按提示安装。压缩包提供 CLI/浏览器版本。

升级前关闭旧界面、停止旧后台，再替换程序。本机数据保留。macOS 安装包未配置开发者签名时会提示来源未知，请确认从本仓库下载后再允许打开。

后续 v4.0 系列修复使用 v4.0.x。

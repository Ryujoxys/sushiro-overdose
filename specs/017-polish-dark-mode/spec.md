# 体验打磨与深色模式（v4.0.2）

## 目标

  保持“选店、记录、看规律”和独立手动取号的主流程，提升新用户上手、取号后跟进和夜间使用体验。不增加自动取号、云同步或新的导航页面。

## 本轮范围

  - 页面、图表和原生窗口跟随系统深色外观；保留寿司郎红白视觉。
  - 新用户在记录页看到三步引导；有第一条个人记录后收起，全零统计不显示。
  - 取到号后显示当前叫号、还差几号和进度；取号页定时刷新时一并刷新预计入座。号码小于当前叫号时提示可能过号。
  - 实时排队显示相对更新时间。
  - 设置页手动检查更新；有新版本时打开固定的 GitHub 发布页。
  - 未开始记录时不显示“已暂停采集”。

## 状态与验收

  1. 号码进度只读取现有 `/api/queue/advisor`，不新增官方写接口；刷新不会重复提交取号或取消。
  2. 检查更新只在用户点击时访问 GitHub；失败结果最多缓存 1 分钟。
  3. 原生窗口不接受页面传入的外部地址；桌面桥新增的 `/api/update` 只允许 GET。
  4. 深色模式下文字、按钮、焦点圈和图表线保持可读，窄屏无横向滚动。
  5. 引导和统计显示只依赖已读取的服务状态，不写配置、不启动采集或自启动。

## 暂不增加

  不新增自动更新下载、后台定时检查更新、通知中心或手动切换主题开关。

# 随应用分发的历史数据

## 目标

首次打开就能查看真实排队历史曲线，不需要账号，也不连接线上数据库。历史数据是随代码固定的一份包，明确标注截止日期；用户可以关闭历史参与，只看自己的采集。

## 行为

- 默认包含内置历史，并自动选中有数据的门店展示曲线，不自动开始采集。
- 按门店、时间范围、日期类型和具体日期查看半小时曲线。
- “包含历史数据”默认开启，关闭选择在本机持久化，重启保持；不会删除任何记录。
- 标注历史数据起止时间、版本及来源，不把旧数据说成实时数据或用户自己采集的记录。
- 图表中的历史样本和本机样本分别计数，同店同日同半小时优先用本机代表值。
- 数据包只用于历史曲线；原有个人模型、实时排队和取号预测不注入内置数据。

## 边界

- 维护者显式运行导出脚本，使用只读凭证查询公开门店数据；构建、发布、应用启动不导出或更新数据包。
- 包内不含数据库地址、token、个人凭证、手机号或个人票号。
- 原始数据优先，已归档的早期日期使用逐日半小时代表值；未知不补零，非营业不计等待分布。
- 包与本机 JSONL 分开保存。导出“我的记录”仍只导出本机快照。
- 不恢复 GitHub 登录、数据库客户端或任何自动取号。

## 验收

- 断网且本机无历史时，首页能展示包内门店曲线和真实截止时间。
- 关闭开关后，没有本机记录则显示空状态，不偷偷回退内置历史。
- 时间筛选不把过期历史移动到今天；默认全部历史，最近范围按当前日期计算。
- 测试覆盖数据包校验、零值与缺失、重叠优先级、时间过滤、开关持久化、无网络访问及小屏。

## 叫号曲线

- 默认查看“叫到几号”，可切换“等多久”，号码和分钟不共用纵轴。
- 点选、键盘或拖动时段后，显示该半小时通常叫到的号码、历史 P20-P80 范围和有效样本天数；单日或少样本只称记录，不伪装成稳定规律。
- 叫号使用公开堂食最大叫号，不包括预约队列，不代表特定桌型已经轮到。跨日统计在同一时段进行，不把号码差当叫号速度。
- 固定包补充可空 `display_called_no`；早期逐日表只接受 `called_sample_count = 1` 的代表值。0、负数、缺失不补号。
- 叫号和等待分别统计有效样本；等待缺失不抹掉真实叫号。关闭历史后，两种曲线都只用本机记录。

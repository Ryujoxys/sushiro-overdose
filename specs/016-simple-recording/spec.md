# 日常记录与项目展示

## 目标

  保持“选店、记录、看规律”的主流程。手动取号独立保留，不增加自动取号、云同步或新的导航页面。

## 本轮范围

  - 选店弹窗始终显示已经选择的记录门店，搜索其他城市时也能核对和移除。
  - 允许清空记录门店，暂停采集，不删除任何历史记录，不回退到旧的取号偏好门店。
  - 明确选择的记录门店不被旧提醒配置追加，移除某店后不能在刷新时重新出现。
  - 已有自启动可以独立关闭；清空门店不修改系统自启动。
  - 图表门店搜索兼容历史包的地区字段，城市为空时仍能按城市或区域找到门店。
  - README 以真实界面、下载入口和简短使用说明为主。GitHub 简介和主题词匹配当前定位。

## 状态与验收

  1. 跨城市搜索时，已选列表保留；移除后搜索结果的勾选状态同步。
  2. 搜索失败时仍可移除已选门店，历史数据不受影响。
  3. 清空保存后采集关闭；重新打开应用或后台服务也不能改为记录旧偏好门店。
  4. 取消弹窗不保存选择；保存失败保留选择和可重试操作。
  5. 记录和取号的选店行为独立，取号仍必须选择一家并经过确认。
  6. 截图使用隔离目录、内置历史或明确的演示数据，不出现个人账号、路径或凭证。
  7. 内置历史关闭后，自己的记录仍可使用已有门店地区信息检索，但不计入历史样本。

## 暂不增加

  不新增账号体系、在线数据库、通知中心、多套工作区或自动抢号。备份恢复和图表视图记忆留待单独评估。

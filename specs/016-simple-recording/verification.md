# 验证记录

## 本轮结果

  - 已选门店在搜索结果之外单独显示，跨城市搜索时保留，可逐项移除。
  - 清空门店会暂停采集，不回退旧偏好，不追加旧提醒门店，不删除历史或自启动。
  - 旧提醒仅能影响实际记录中的门店，不会改变无关门店的采集间隔。
  - 图表搜索保留本机 city/area；缺失字段才用历史包补齐。关闭历史不会恢复历史样本。
  - README 使用应用图标、版本标记、曲线截图、分平台下载和双栏使用说明；安装细节折叠。配图沿用 v4.0.1 的真实界面，与下载版本一致。
  - GitHub 简介改为当前用途，主题词保留本地记录、桌面、数据可视化和平台信息，未填写过期网站。

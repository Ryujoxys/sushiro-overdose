# 实施计划

## 应用

  沿用现有选店弹窗及红白视觉。已选列表直接使用当前门店缓存；不为移除门店请求远端。显式配置不能追加旧提醒门店；空列表不能被 NormalizeQueueBaselineConfig 改为旧偏好门店。保存空列表须关闭采集，但保留本机历史文件和系统自启动设置。未声明 use_preference_stores 的旧配置继续保留原有兼容行为。

## 边界

  不新增官方 API 调用，不修改账号认证、手动取号、代理或证书。只写现有公开采集配置；如需刷新采集状态，沿用现有服务机制。系统自启动只响应用户显式开关。

  图表搜索兼容内置包的 area 字段。历史开关控制样本合并，不应清掉本机门店用于检索的地区元数据；元数据回填不写入个人模型。

## 展示

  README 使用现有应用图标、真实界面截图及 GitHub 可渲染的图片/表格。技术和安装细节折叠展示。介绍不承诺精准入座时间，也不暗示采集无需网络。

## 验证

  Go 测试覆盖空列表与旧偏好兼容，前端测试覆盖跨城市选择、移除、失败、取消和取号独立性。浏览器验证使用独立 SUSHIRO_DATA_HOME，不覆盖 HOME，不触发认证或真实取号。核对 GitHub 介绍、主题词和 README 链接。此次不打版本标签。

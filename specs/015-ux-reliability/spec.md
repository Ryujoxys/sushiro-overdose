# 本地记录体验修复

## 目标

用户能直接选店、开始记录、查看自己的曲线；认证和手动取号遇到失败时有明确退路。保留现有红白视觉，不增加自动取号。

## 范围

- 原始个人记录不再因行数上限被自动删除。
- 取消号码必须绑定用户看到的账号与号码，变化时拒绝并要求重新查询。
- 修复手机认证说明、停止入口、凭证验证状态和认证后的查询恢复。
- 首页优先展示记录控制；图表选店支持搜索、键盘操作及空结果。
- 导出明确当前筛选，不允许无个人记录时导出空文件；设置提供全部记录备份。
- 实时页面进入、恢复和停留时只读刷新；失败明确标示旧数据。
- 自启动检查目标位置，提供显式更新；提供退出应用及后台记录入口。
- 统一控件尺寸，减少无意义重绘和设置说明。

## 验收

1. 超过旧行数上限仍保留全部个人原始记录，查询与备份仍可读取。
2. 缺少取消确认对象、账号变化、号码变化、查询失败均不调用官方取消接口。
3. 认证验证失败不会显示连接成功；停止不清空导入内容；查询认证完成后只恢复查询，不取号。
4. 手机端没有已删除的步骤或按钮，无局域网地址时不展示回环二维码。
5. 保存记录门店后图表切换到所选门店，但不会自动开始记录或开启自启动。
6. 图表选店可输入店名或城市搜索，支持方向键、回车、Escape 与无匹配提示。
7. 导出只含个人记录，当前筛选与全部备份分开。
8. 界面自动刷新不产生取号、取消、认证或系统设置副作用。

## 边界

- 不发版，不改版本号，不删除用户数据，不迁移线上数据库。
- 本轮不新增备份导入协议；全部备份使用既有 JSONL 导出协议。
- 官方取消接口只按账号操作，本地前置核对不能消除手机端并发变更的全部风险。
- Windows、手机证书与真实微信认证未实机验证时必须明确说明。

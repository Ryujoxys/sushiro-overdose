# 日常使用体验整理

## 目标

让第一次使用的人从首页明确开始选店取号，回访用户能快速查看号码；选店、人数、认证和提交状态连续可见，不需要先理解全部功能。

## 范围

1. 首页突出一个取号入口；导航使用具体任务名称，帮助和本机分析为次要入口。
2. 选店弹窗区分单选、多选；搜索失败可以重试，空选择不能误确认，键盘可完成操作。
3. 取号确认中可直接修改成人、儿童、桌型。首次认证保留这次选择，认证完成后仍需明确确认，超时只引导查询。
4. 本机分析先选择门店，再显式开启后台或登录自启动。暂停、数据量、当前状态清楚可见，技术细节折叠。
5. 优化窄屏触控、焦点与错误反馈；修复异步门店结果覆盖新选择的问题。

## 非目标

不替换品牌视觉，不新增远程服务、账号登录或官方写接口，不调整预约引擎。不上线、不运行应用服务、不实际取号、不修改本机代理或自启动。线上只读 key 继续不处理。

## 状态与验收

- 选店未加载、失败、无匹配和已选择均有明确文案；输入搜索回车不得确认旧选择。
- 取号对话框展示真实目标门店；人数不合法时就地提示并保留输入。
- 无认证时主按钮明确为认证；关闭认证清空本次待办，迟到响应不能恢复或提交。
- 认证后重回可编辑确认框；一次确认最多提交一次。失败不会自动重试取号。
- 本机服务无门店时只选门店；选择本身不开后台、不启用自启动。
- 快速切换关注门店后，旧请求不得覆盖当前门店。
- 新增行为用隔离的前端测试和现有 Go 测试验证。视觉和真实系统运行结果不作已验证承诺。

# 隔离预览与钥匙串修复

## 问题

为隔离预览数据而覆盖 `HOME` 会使 macOS 的 `security default-keychain` 找不到用户钥匙串。原有兜底逻辑又拼接不存在的钥匙串路径，导致用户被引导反复安装证书。

## 范围

- 使用 `SUSHIRO_DATA_HOME` 隔离应用数据和 CA 文件，不覆盖系统用户目录。
- 默认数据路径保持兼容；隔离环境不迁移旧凭证，不注册或删除正式环境自启动项。
- macOS 无有效默认钥匙串时，在安装前终止并给出明确提示，不创建钥匙串或改变默认钥匙串。
- 不自动信任证书、不自动修改代理，不进行真实取号。

## 验收

- 独立数据根目录包含 `.sushiro` 和 `.sushiro-proxy`，系统 `HOME` 不变。
- 缺失、空值、无效路径及命令失败均不会进入证书安装命令。
- 页面区分钥匙串不可用和证书未信任，不再建议盲目重装。
- 测试以模拟命令验证，预览仅只读核对钥匙串路径。

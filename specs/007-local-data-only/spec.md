# 本地数据收敛与流程审查

## 目标

取消桌面端 GitHub 登录、云端基准和数据库直连。公开实时信息仍读取寿司郎官方只读接口；历史、预测、用户单据与凭证仅保存在本机。未来开放线上服务时复用既有版本化数据协议，不混入个人凭证或单据。

## 范围

- 删除桌面端云端请求、登录界面和回调处理；旧入口明确返回已下线。
- MCP 改用桌面端只读 API，不再接收或转交数据库密钥。
- Worker 源码收敛为停用响应，阻止旧客户端继续走 OAuth 或读取基准。实际线上停服需部署该版本或删除 Worker，不能以源码改动替代。
- 保留本地快照、观测、会话及基准导出协议；旧本地历史不删除、不上传。
- 静态审查 Windows 捕获、预约、排队、采样、通知和页面状态；修复可独立验证的缺陷。

## 行为

| 场景 | 预期 |
|---|---|
| 首次使用，无本地历史 | 展示数据不足及选店、采集入口，不要求 GitHub 登录 |
| 旧云端配置或环境变量仍存在 | 不读取、不发起云端请求，不恢复远端连接 |
| 旧登录或回调 URL | 返回 410，不接收、不保存 session |
| 官方只读接口不可用 | 显示失败，不伪造实时数据、不执行取号或取消 |
| 本地状态并发更新 | 预约槽和排队槽互不覆盖，损坏文件不被静默替换 |
| 系统缺少 IANA 时区库 | 大陆门店日期仍按 UTC+8 处理 |

## 安全边界

本次不新增任何官方写 API，不混用预约和排队的取消接口，不启动本地应用、不安装证书、不改系统代理、不使用真实凭证、不实际取号或取消。测试使用临时目录及模拟服务。线上数据库、既有采集器和用户历史不删除。

## 验收

- [x] 页面、桌面端、MCP 均无 GitHub/数据库连接入口。
- [x] 旧 URL、配置和环境变量不能恢复远端数据访问。
- [x] 本地历史预测仍可用，空数据状态不推荐已删除功能。
- [x] 数据契约文档包含版本、时间、门店标识、缺失值和隐私边界。
- [x] 测试、静态检查、Windows 交叉编译通过；真机未验证项目明确标注。

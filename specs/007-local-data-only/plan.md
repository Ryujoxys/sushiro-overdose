# 实现方案

## 模块变更

| 模块 | 变更 |
|---|---|
| 云端认证和远端基准客户端 | 删除网络实现；旧认证路径统一 410 |
| 排队图表和预测 | 只读取本机 JSONL，保留协议结构及纯计算函数 |
| 页面 | 移除云端状态、操作、配置和引导，说明本机数据来源 |
| 公开采集配置 | 门店页提供无需认证的显式选店/启用/暂停入口，关注列表与后台采集列表不再隐式混用 |
| MCP | 用桌面端只读接口替代数据库客户端，不传数据库密钥 |
| Worker | 所有路径返回 410，无外部请求 |
| 核心状态 | 原子写及读改写互斥，避免单据覆盖 |
| 时区 | 大陆门店使用已有 UTC+8 常量，不依赖系统时区库 |
| 预约响应解析 | 未知信封或 null 返回错误，禁止当空列表清理本地预约 |
| MCP 启动 | 补齐模块入口，兼容原有 Claude Desktop 注册命令 |

## 本地状态

| 文件 | 读写与清理 |
|---|---|
| `queue_baseline.jsonl`、`queue_observations.jsonl` | 原采集器写入，本地图表读取，保留现有裁剪规则 |
| `queue_sessions.jsonl` | 仅本机分析，绝不纳入公开导出 |
| `cloud_auth.json`、`queue_baseline_remote.json` | 不再读取；不擅自删除用户文件 |
| `mcp_config.json` | 只保留功能开关；旧数据库字段忽略，后续保存不再写出 |
| `.sushiro_state.json` | 单进程事务更新预约/排队独立槽；跨进程争用另列审查风险 |

## 验证策略

Go 单元测试、竞态测试、模拟请求验证零云端访问、JavaScript 语法检查、Node Worker 停用测试、Python MCP 接口契约测试、六平台交叉编译。无需运行本地服务或触发官方写操作。Windows 的 PAC、UAC、证书、微信网络栈仍需真机验收。

## 上线边界

仅准备源码，不提交、推送、打标签或部署。线上停服需要发布停用 Worker 并撤销旧数据库只读 token / OAuth secrets，避免旧安装包仍可访问旧服务。

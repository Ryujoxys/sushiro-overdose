# 实施方案

## 安全边界

删除宪法中凭证验证允许创建和取消排队号的例外。验证复用只读探测，明确无法证明写接口可用。查号只返回官方记录与当前计划，不调用成功处理器。

## 生命周期

引擎以未关闭的运行句柄而非可变显示状态判断占用；增加停止中状态，工作协程拥有最终清理权。定向时段随启动一起保存。捕获落盘与认证重置使用同一串行边界及代次，手机会话同时检查 token。捕获设置超时并在阻塞步骤后检查取消。

## 提醒与状态

公开采集负责叫号提醒，目标包含启用规则的门店；避让活跃主流程，但不因持有排队号暂停。接口及 UI 显示公开采集状态和最近结果。凭证保存只标未验证，只读探测按实际认证结果更新。

## 平台与资源

Windows 代理写入使用可测试事务层；保存被修改的注册表值，失败或恢复时回放，恢复失败保留备份。取消机器级 WinHTTP 写入，不再以普通权限桌面程序修改不可可靠恢复的全局配置；旧版缺少备份的残留明确报错，不擅自清空用户原代理。MCP 使用 Go embed 内嵌白名单资源，按内容摘要释放到用户私有目录，不下载源代码。

## 验证

补充模拟 API、生命周期竞争、过期会话、公开提醒、代理事务逐步失败和资源释放测试。运行 Go race/vet、前端纯逻辑测试、Python 本地适配测试及各目标平台交叉编译。不启动应用服务、不执行真实推送。

# 本地记录为主，保留手动取号

## 目标

用户下载后先选门店、开始记录，在本机查看自己的排队规律。无需认证即可记录公开数据。手动取号独立保留，不再提供任何自动抢号。

## 范围

- 首页为“我的记录”，包括门店、记录状态、时间分布、样本量及 JSONL 导出。
- “手动取号”保留实时排队、人数、桌型、明确确认和已有号码查询。
- “想几点吃”只提供建议；样本不足时不编造时间，不创建计划。
- 狙击、循环预约、定时取号、每日自动计划删除；旧接口返回 410，旧计划读取为禁用。
- 认证必须由用户启动，完成后返回确认，不能直接取号。
- 设置只展示数据位置、取号账号及故障恢复，保留品牌配色。

## 状态与边界

- 记录区分未开始、运行、暂停、认证避让、采集失败；暂停不清数据。
- 自动启动独立确认，不随选店或开始记录隐式安装。
- 图表只展示本机实测样本；非营业、缺失时段不能算作零等待。
- 取号超时或返回不明确时先查询，不自动重试。
- 旧数据、凭证和结果文件保留，不做 Git 回滚。
- 只读 API、认证探测、后台服务不得调用预约、取号或取消接口。

## 验收

- 新用户不用连接账号即可选店并启动公开记录。
- 桌面和移动尺寸均可操作，空状态与少量样本可理解。
- 自动操作在 CLI、路由、启动调度和前端均无执行入口。
- 单次确认最多提交一次取号，认证结束不提交取号。
- 测试不安装证书、不改系统代理、不发真实通知或订单。

# 本地桌面应用

## 目标

Windows 和 macOS 下载后直接打开应用窗口。以本机记录为主，需要时手动认证、确认取号。沿用现有红白视觉和数据格式。

## 范围

1. 使用系统 WebView 承载现有页面，不依赖用户安装 Chrome 或 Edge 浏览器。
2. 同一数据目录只运行一个桌面窗口；重复启动唤起已有窗口。
3. 关闭窗口退出界面进程、清理认证代理；用户已开启的独立采集服务继续运行。
   - 手动请求或导出尚未完成时，提示稍候关闭，避免中断已确认的操作。
4. 导出记录和诊断包使用系统保存对话框，取消不写文件。
5. 浏览器及 CLI 版本继续可用；本地 HTTP 端口仍仅监听回环地址。
6. README 缩短，配真实界面截图，只介绍当前产品。
7. 本次发布 v4.0.1，后续修复使用 v4.0.x。完整新版本公开后，清理旧 Release 页面及附件，保留 Git 标签与历史。

## 不做

不修改取号、取消、认证协议，不引入自动取号，不接入共享数据库，不迁移个人历史格式，不重写前端框架。

## 验收

- macOS 原生窗口实际打开、加载内置曲线，支持筛选和关闭。
- Windows amd64、arm64 原生程序编译通过；无 Windows 实机时明确标注验证边界。
- 重复启动、端口占用、取消导出、关闭窗口和后台独立性有测试或可重复检查。
- 原生通信不能访问任意 URL，不能绕过现有手动确认及 API 安全边界。
- 自动检查不弹真实通知、不启动认证、不提交真实订单。

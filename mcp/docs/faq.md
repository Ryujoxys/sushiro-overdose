# 使用常见问题

## 凭证

只看公开排队不用寿司郎凭证。预约、取号、取消及个人单据需要从微信小程序导入凭证。设置页向导提供获取步骤。

Windows 当前界面优先引导手机导入；PC 捕获是否可用取决于微信版本、代理和证书环境，不能简单断言所有 Windows 都不支持。捕获完整字段、只读验证成功与真正可取号是不同状态。

401/403 等错误提示凭证可能失效，不能仅凭某个服务端通用错误断言唯一原因。先看脱敏诊断，再重新获取；不要把完整 token 或抓包发到公开 issue。

## 排队预测

实时叫号来自官方公开接口，历史曲线来自本机采样。不再连接共享数据库或使用 GitHub 登录。

第一次使用可能只有实时状态、没有历史。选择常用门店、开启公开数据采集并保持桌面端运行后积累历史。预测必须连同样本量、数据时间、可信度和区间阅读，不能保证到店即可用餐。

## 通知

设置中可以配置飞书、Telegram、Bark、Server酱并发送测试。测试成功只证明渠道可达，不代表采集和提醒评估一直运行。目前自动取号后采样避让可能阻断叫号提醒，仍应结合小程序确认状态，见代码审查报告。

## 数据与隐私

凭证和个人排队记录存放在本机 `~/.sushiro/`，不纳入公开基准协议。通知功能会把所需通知内容发送到用户配置的渠道；使用 AI 查询个人单据时，结果会返回给用户选择的 AI 客户端。

## 本机助手

在桌面端「设置 → MCP 助手」启用，或手动安装。本机助手所有数据查询都需要桌面端运行；不再填写任何数据库 URL/token。旧配置中的数据库字段会被忽略。
